# Pulse — Personal GitHub Command Center

A personal, mobile-first developer operations cockpit powered by GitHub. Pulse turns repositories, commits, pull requests, CI results, stars, forks, issues, releases and activity into a real-time visual command center.

**GitHub is the data source. Pulse is the interface.**

## Product pillars

- **Command Center** — the default screen; a live overview across all (or a selected) repository.
- **Repositories** — track every repo with actual GitHub statistics.
- **Activity** — a live signal feed.
- **CI & Workflows** — pipeline health and status across projects.
- **Community** — stars, forks and reach.
- **Health** — repository reliability and maintenance.
- **XP & Rewards** — turn shipping into a reward system.

## Repo selector

The selected repository stays globally accessible via the pill next to each section header. Selecting a repository updates the entire dashboard context. Choose **ALL REPOSITORIES** for the full picture.

## Tech

- Pure static frontend (HTML / CSS / JS) — no build framework, stays lightweight.
- PWA-ready: `manifest.webmanifest` + `sw.js` service worker.
- Data snapshot generated by `build.mjs` via the GitHub CLI.
- Best-effort live refresh from the public GitHub REST API (no credentials exposed in the static bundle).
- Distributed dark-first bento-grid cockpit UI with glass surfaces, large metrics and state-communicating animation.

## Deploy to GitHub Pages

The GitHub Actions workflow (`.github/workflows/deploy.yml`) builds the data snapshot and deploys the static site to GitHub Pages automatically on every push to `main`.

```bash
npm run build   # regenerate data/snapshot.json from your GitHub account
```

## Local preview

```bash
npm run start   # serve the static site
```
